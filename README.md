A one-line entry for make.fun's "Worst Superpower" bounty: a program that writes the most useless superpower imaginable to `/output/entry.txt`. The power is pausing time for exactly one second — but only while asleep, so its wielder wakes up one second later, none the wiser. God-tier power, zero utility: the joke is that the most dramatic superpower in comics achieves literally nothing.

## Run it

```sh
python3 main.py
```

This writes a single 115-character line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Deterministic: no input, no randomness, no network.
